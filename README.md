# hx

Сборки приложения hx для Mac с Apple Silicon (M1 и новее), macOS 13 или новее.
Builds of the hx desktop app for Apple Silicon Macs (M1 or later), macOS 13 or later.

**Скачать / Download:** [hx-arm64.dmg](https://github.com/compampa/hx-releases/releases/latest/download/hx-arm64.dmg)

Установка: откройте образ и перетащите hx в «Программы». Что делать при первом запуске и что
поставить самим (git, агенты Claude Code или Pi), написано в файле «Установка — Install.txt» в образе.
Установленное приложение само проверяет новые версии здесь и предлагает обновиться.

Install: open the image and drag hx to Applications. First-start steps and what to install yourself
(git, the Claude Code or Pi agent) are in "Установка — Install.txt" inside the image. The installed
app checks for new versions here and offers to update.

This repository holds release files only (the app, the update archive and `latest.json`).
